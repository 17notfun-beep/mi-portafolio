# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Negocios pequeños, medianos, PyMEs y cualquier persona o empresa que necesite presencia web profesional. Situación típica: un dueño de negocio o emprendedor que necesita una página web para mostrar su oferta, captar clientes o vender online, sin tener conocimientos técnicos.

## Product Purpose

Servicio de creación de páginas web profesionales. El sitio funciona como tarjeta de presentación y generador de leads para Ezequiel, mostrando sus servicios, proyectos realizados y testimonios de clientes para generar confianza y convertir visitantes en consultas.

## Positioning

Rapidez de entrega, diseño moderno y profesional, y comunicación directa y disponible 24hs. La combinación de velocidad + calidad visual + trato cercano es la propuesta diferencial frente a agencias tradicionales o freelancers lentos.

## Operating Context

El flujo del cliente: visita la web → conoce servicios y proyectos → lee testimonios → contacta por WhatsApp o formulario. El sitio opera como_portfolio público y canal de captación de clientes.

## Capabilities and Constraints

- Landing pages, sitios corporativos, e-commerce, y optimización SEO
- Tecnologías: Next.js 16, React 19, Tailwind CSS 4, Framer Motion, Three.js
- Idioma: español (Argentina)
- Un solo proyecto demostrado publicado (Farmacia Aguilera)
- Testimonios de 3 clientes como prueba social
- El sitio es una sola página (SPA) con secciones de scroll

## Brand Commitments

- Nombre: Ezequiel Serer
- Tono: profesional pero cercano, directo, sin tecnicismos innecesarios
- Identidad visual aún en definición

## Evidence on Hand

- Proyecto publicado: Farmacia Aguilera (https://farmacia-aguilera.vercel.app/)
- 3 testimonios reales de clientes
- Servicios documentados: Landing Pages, Sitios Corporativos, E-commerce, SEO

## Product Principles

1. Rapidez sin sacrificar calidad
2. Diseño moderno y profesional como estándar mínimo
3. Comunicación directa y disponible para el cliente
4. Resultados medibles (conversión, velocidad, SEO)
